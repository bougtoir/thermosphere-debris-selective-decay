## 4. Gaussian comparator: sensitivity to the matching criterion

The static Gaussian is an idealized diagnostic baseline, not a realizable intervention. Each matching
criterion answers a different question: *peak_matched_fit* (the Gate 4 comparator: GITM grid maximum,
half-e area width, half-max window); *source_centred_sigma_src_peak_amp* (the baseline's own
representation: source position and width, GITM peak amplitude); *width_matched_rg_centroid* (centre =
Δρ⁺ centroid, σ = R_g/√2 at the time of peak — handles displaced/asymmetric peaks);
*integrated_density_matched* (amplitude chosen so that the Gaussian's ∫Δρ dA dt over its window equals
GITM's over the whole run: the same mass-time kept localized); *orbit_exposure_matched* (amplitude chosen
so the shell-mean extra Δv equals GITM's). Static-Gaussian selectivity does not depend on amplitude, so
the last three share one selectivity.

## 4b. Why the peak-matched comparison differs between grids (fit-ingredient swaps)

`scripts/physical_g4t_gaussian_decomposition.py` recomputes the peak-matched comparator on each grid
while replacing one fit ingredient at a time by the coarse-grid value (centre, σ, half-max time window)
or by a sub-grid centre (anomaly-weighted centroid above dmax·e^-1/2, not quantized to a cell). GITM
selectivity is unchanged by these swaps; only the comparator moves. The amplitude cancels in the ratio.
