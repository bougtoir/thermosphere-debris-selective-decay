# Data and code availability

## Code

All analysis code is public at
`https://github.com/bougtoir/thermosphere-debris-selective-decay`
under the license in `LICENSE`, and is included in the submission
package under `07_code/`. The full study regenerates with:

```
make clean
make all      # full pipeline: phases, audits, figures, tables,
              # manuscript, QC, submission package
make quick    # fast smoke reproduction
make test     # unit and regression tests
```

Dependencies are pinned in `requirements.txt` (conda equivalent in
`environment.yml`). All stochastic components draw from the single
seed in `config/default.yaml`, so runs are deterministic.

## Data

No proprietary, restricted, or third-party observational dataset was
used or redistributed. Every number in the manuscript is model output
generated by the code in this repository, and is written into the
manuscript directly from the result CSVs by
`scripts/build_manuscript.py`; no scientific value is hard-coded in the
text.

- Background neutral density comes from the NRLMSISE-00 empirical
  model evaluated locally through its public Python implementation
  (pinned in `requirements.txt`); the model is cited in the
  references. No external density observations were downloaded.
- Case definitions (synthetic target and protected objects) are in
  `data/processed/cases.csv`, with field definitions in
  `data/processed/DATA_DICTIONARY.md`.
- Generated result tables are in `results/tables/*.csv` and are
  shipped in the submission package under `06_data/tables/`.
- Value-level provenance for every number injected into the
  manuscript is in `results/manuscript_value_provenance.csv`, and the
  citation order is in `results/manuscript_citations.csv`; both are
  checked automatically by `scripts/qc_traceability.py`.

## Pre-revision state

The state of the study before the final revision (including the
results produced before the NRLMSISE-00 density-unit correction) is
preserved at git tag `pre-revision-checkpoint` and described in
`docs/PRE_REVISION_STATE.md`. Superseded results were not deleted or
silently overwritten; `docs/REANALYSIS_PLAN.md` records what changed
and why.
