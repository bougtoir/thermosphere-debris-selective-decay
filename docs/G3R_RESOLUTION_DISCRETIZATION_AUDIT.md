# G3R — Resolution and discretization robustness audit

Generated by `scripts/physical_g3r_g4t_docs.py`. Sources: `results/tables/physical_g3r_realized_forcing.csv`,
`results/threshold_sensitivity.csv`, `results/tables/physical_g3r_spread_metrics.csv`,
`results/orbit_interpolation_sensitivity.csv`, `results/grid_sensitivity_metrics.csv`.

Two kinds of grid dependence are kept apart:

* **A — physical-model discretization**: the GITM solution itself changes with the grid (10°×5° vs 5°×2.5°; same 50 altitude levels, same time-step control). Tested only by the c8b pair.
* **B — diagnostic/aggregation dependence**: the same GITM fields give different metrics because of thresholds, interpolation, output cadence, orbit step, coordinate conventions or the diagnostic grid. Tested on existing output without rerunning GITM.

## 4. Numerical diffusion vs physical transport (A/B)

dissipation terms), so the mechanisms cannot be separated directly. No numerical-diffusion coefficient

Fits over 0.5–4 h after onset: `rg_growth_linear` is dR_g/dt of a linear fit (ballistic/wave-like spread);
`D_eff_if_diffusive` is the coefficient a purely diffusive spread (R_g² = R_g0² + 4Dt) would need. Both
forms are reported; R² values close to each other mean the time series cannot discriminate them. The
comparison with the anomaly-weighted perturbation wind |Δv_h| shows whether advection by the heating-
driven wind can account for the spread rate. The decisive A-type test is the coarse/fine comparison
(Section 6): numerical diffusion in GITM's scheme scales with grid spacing, physical wave propagation
does not.
