# Numerical-zero and selectivity audit (Phase 3)

Addresses hostile-review item **C2**: the frozen selectivity table reported
ratios of 1.2e80 (pair D) and 2.4e80 (pair G), produced by dividing a finite
target delta-v by a protected-object delta-v of order 1e-84 m/s.

Generated by `scripts/audit_numerical_zero.py` ->
`results/tables/numerical_zero_audit.csv`,
`results/tables/selectivity_classified.csv`.

## Where the tiny numbers come from

The perturbation is a Gaussian in horizontal and vertical separation,

    delta(r) = delta_max * exp(-d_h^2 / 2 sigma_h^2) * exp(-d_v^2 / 2 sigma_v^2)

with no compact support: it is nonzero everywhere in double precision until
the exponent underflows (~ -745, i.e. ~38 sigma). A protected object on a
different orbital plane never approaches the tracked target, so the code
faithfully integrates the exp(-182) tail and returns 1e-84 m/s. That value is
arithmetic about the functional form of the model, not a statement about
atmospheric drag on a spacecraft.

Frames and distances were re-checked in the process: separations are computed
between simultaneous ECI positions of object and patch centre (same epoch,
same frame), the vertical term uses the radial difference, no mask or
normalisation is applied, and no underflow-to-zero occurs before ~38 sigma.
The geometry is therefore correct; the defect is interpretive, not a coding
error.

## Classification

For every object, scenario and the same 24 h window we record the peak delta
seen by the object, the closest approach expressed in Gaussian sigmas, the
encounter count (delta > 1e-6, the in-patch threshold used by the exposure
integrator), the absolute extra delta-v and its ratio to the *natural* drag
delta-v the same object accumulates over the same window.

| class | criterion | interpretation |
|---|---|---|
| `no_encounter` | closest approach > 6 sigma, or peak delta <= 1e-6 | the object never meets the patch; any nonzero delta-v is Gaussian-tail arithmetic |
| `below_numerical_resolution` | extra dv < 1e-12 x natural drag dv | unresolvable against the background integration in double precision |
| `gaussian_tail` | extra dv < 1e-3 x natural drag dv | mathematically nonzero, physically negligible (far below MSIS density uncertainty of ~15%) |
| `physical_exposure` | extra dv >= 1e-3 x natural drag dv | a genuine, if small, perturbation |

The 1e-3 boundary is deliberately generous: MSIS climatological density is
itself uncertain at the ~15% level, so any collateral below 0.1% of natural
drag is unobservable in principle, not merely in this model.

## Consequences for the manuscript

1. **The only defensible localized selectivity measurement in this study is
   pair E: ratio ~3.7e2**, obtained where the protected object genuinely
   encounters the patch (29 crossings, collateral 6.3% of its natural drag).
   Pair A is tail-limited (collateral 5.4e-5 of natural drag) and pairs D and
   G are geometrically undefined.
2. Ratios for `no_encounter` pairs are reported as **undefined**, never as
   numbers. `selectivity_ratio` is retained in the CSV for traceability but
   carries `ratio_status` and `ratio_meaningful` columns; figures and the
   manuscript plot only absolute delta-v.
3. The Pareto and selectivity figures are regenerated on **absolute target
   benefit vs absolute protected collateral**, with non-encounter points
   marked at the axis floor rather than at 1e-84, and the classification
   encoded by marker style.
4. The physical statement that survives is geometric and unglamorous: a
   protected object avoids collateral drag if and only if it never enters the
   enhanced volume. Where orbits cross or share a plane (pair E, and the
   co-orbital negative control) selectivity collapses to O(1)-O(1e2),
   independent of how sharp the patch is.
