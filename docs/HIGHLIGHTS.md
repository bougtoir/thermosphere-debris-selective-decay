# Highlights

- Localized thermospheric density enhancement is tested as a feasibility
  boundary problem, not a hardware concept.
- Sustained co-location, not peak amplitude, bounds selective drag:
  Earth-fixed pulses are negligible per event (~µm/s).
- An idealized on-target tracking bound yields mm/s–cm/s/day and
  selectivity >10^5 against remote protected objects.
- Selectivity provably fails for co-orbital and track-crossing
  spacecraft and for dispersed fragment clouds.
- Horizontal diffusion/advection let only a minority of plausible
  patches survive one hour — the practical window is likely closed.
